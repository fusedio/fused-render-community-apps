How this works, and what it deliberately ignores

Every number on this page comes from fused-render's file index — a parquet table of your filesystem that a background scan already built. Nothing here walks your disk, stats a file, or reads a byte of content. Each bit is one SELECT, run read-only inside the index's own guarded DuckDB session.
