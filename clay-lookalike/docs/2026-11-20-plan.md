# Clay Lookalike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fused-render app where clicking chips on an aerial map of San Francisco highlights every chip whose Clay v1.5 embedding looks like them.

**Architecture:** `lookalike.py` is a stateless `main(action=...)` that fetches one scene parquet per call into `.fused/cache/`, builds one normalised `emb.npy` + `bounds.bin`, and answers `query` by cosine max-over-positives minus max-over-negatives. `index.html` is a deck.gl page (Esri imagery TileLayer + PolygonLayer of chips) whose state lives in URL params (`pos`, `neg`, `k`), with a thumbnail strip cropped client-side from z18 tiles.

**Tech Stack:** fused-render app API v1, Python 3.11 with numpy + pyarrow + requests (bundled set, empty `dependencies`), deck.gl 9.1.10 standalone from unpkg, Esri World Imagery tiles.

**Spec:** `docs/2026-11-20-design.md`

## Global Constraints
- Scenes: the 19 files under `ca/2020/60cm/rgbir_cog/37122/` for quads 12–14 and 20–22 (list hard-coded in `lookalike.py`).
- Each `runPython` call must finish well under 60 s: one scene per `fetch` call.
- Chips are deduplicated by keeping those whose centre lies inside the scene's nominal quarter-quad box (1/16 degree).
- Embeddings L2-normalised at build time; `query` returns the top `k` (default 1500) `[id, score]` excluding selected ids.
- No runPython, network or jobs under `_preview=1`.
- All colours from tokens; the map panel keeps a fixed dark palette (strong own look).

## Review Focus
- Partial download (page closed mid-way): `status` reports per-scene cache so the next run resumes; `build` refuses until all 19 scenes exist. Test: `status` with 2 of 19 cached.
- Corrupt/short parquet in cache: `fetch` re-downloads when parsing fails. Test: write junk file, call fetch, expect fresh parse.
- Query with no positives: returns empty `top` and the page clears highlights. Test in `test_lookalike.py`.
- Selected ids outside range (stale URL after a rebuild): ignored, not a crash. Test: `pos="999999"`.
- Shift-click on a positive moves it to negatives rather than duplicating. Page-side; verified in the browser.
